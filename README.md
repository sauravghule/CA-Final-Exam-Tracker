# CA Final Command Center — Nov 2026

## Run locally
1. `npm install`
2. `npm run dev`

## GitHub Pages
1. Create a repository named `ca-final-tracker`.
2. Upload all files in this folder.
3. In **Settings → Pages**, set **Source** to **GitHub Actions**.
4. Push to `main` and wait for the Actions workflow.
5. Open `https://YOUR-USERNAME.github.io/ca-final-tracker/`.

Study data is stored in IndexedDB on the device. Use **Dashboard → Backup & Restore → Export backup** regularly.
